# Phone app parity map

Generated by `bun apps/unified/scripts/mobile-parity.ts` from the desktop's own menu, permissions and feature registry. **Do not edit by hand** — change the code and re-run (`--check` fails when this file is stale; `tests/mobile/parity-map.test.ts` runs it).

Seats: owner, admin, manager, staff (the field rung), viewer — permissions, not ranks. "Seats" lists who is shown the item by the desktop's own rule (permission, minimum role, route rules), before any per-business switch. "Switch" says whether the item is part of a new business's default set.

Phase: **A** daily field and office work · **B** projects, bids and the price book · **C** everything else that works on a phone · **D** desktop only (with the reason).
