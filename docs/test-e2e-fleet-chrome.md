# Claude-in-Chrome fleet test — 10 ZZ Fleet verticals

Paste the prompt below into Claude in Chrome. It walks each of the 10
freshly-provisioned ZZ Fleet test tenants (one per vertical) through the
same smoke checklist: public website renders, CMS admin works, CRM login
works, and — critically — no cross-vertical feature leaks.

The prompt is self-contained — Claude in Chrome has no shared context with
the CLI session, so everything it needs is in the prompt itself.

Rebuilt 2026-07-24 via `apps/api/scripts/rebuild-zz-fleet.ts` (comp promo,
`is_test_tenant=true`). Tear down with
`apps/api/scripts/teardown-zz-fleet.ts --delete` when done.

> **FILL-IN NOTE:** the URL table below is populated from the live
> deploys — if you re-provision, re-run the URL query at the bottom of
> this file and update the table before pasting.
